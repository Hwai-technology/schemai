# Feature: QuickFix & Remediation Actions

## 1. Overview
- **Feature Name**: QuickFix & Remediation Actions
- **Assigned Owner**: Sergio
- **Associated ClickUp HUs**: HU-15

## 2. Responsibilities
- Implement VS Code `CodeActionProvider` (`vscode.languages.registerCodeActionsProvider`).
- Offer automated quick-fixes on flagged risk diagnostics:
  - Add standard license attribution headers.
  - Insert required copyright notices.
  - Remove or replace flagged snippet blocks.
- Register remediation commands and workspace edits.

## 3. Scope Boundaries
- **In Scope**: VS Code CodeActions, workspace text edits, attribution snippet generators.
- **Out of Scope**: Diagnostic collection management (handled by `src/alerts/`), raw prompt engineering (handled by `src/llm/`).

## 4. Expected Interfaces & Integration Points
- Exposes:
  ```typescript
  export function register(context: vscode.ExtensionContext): void;
  ```
- Consumes:
  - Diagnostics provided by `src/alerts/`.
  - Explanations generated by `src/llm/`.

## 5. Development & Ownership Rules
- Any team member may change this directory through a pull request. Sergio, as owner, is kept informed; the PR is approved by the reviewer assigned in ClickUp (`rev-*` tag), never by its author.
- Code action workspace edits must be atomic and reversible via standard undo.
